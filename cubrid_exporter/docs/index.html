1. 개요

CUBRID Open API 는 데이터베이스의 런타임 통계를 두 가지 표준 출력구로 제공합니다. 수집기는 백그라운드에서 주기적으로 스냅샷을 캐시하므로, 스크랩/호출이 DB에 부하를 주지 않습니다.

/metrics
OpenMetrics — Prometheus 가 그대로 스크랩. Grafana는 Prometheus 경유. (주력)
/v1/stat/*
JSON — SI 커스텀 연동·비-Prometheus 도구용. (보조)
범위
PostgreSQL parity (pg_stat_* level). No Oracle AWR/ASH-level depth.
메트릭 규약
counter 는 누적·단조증가(소비자가 rate()로 변화율 계산), gauge 는 순간값. 단위는 seconds·bytes·ratio 로 정규화.
⚠️ 의미 주의: cubrid_sql_*_total 은 SQL 문 실행 횟수이며 PostgreSQL tup_*의 행 수가 아닙니다. 캐시 히트율은 PG와 동일하게 소비자가 rate(blks_hit)/rate(blks_fetched) 로 계산합니다.

2. 인증

서버에 CUBRID_API_TOKEN 환경변수를 설정하면 모든 데이터 엔드포인트가 Bearer 토큰을 요구합니다(미설정 시 비활성). Prometheus·curl 모두 표준 Bearer 를 지원합니다.

# 서버 기동(토큰 보호) — 단일 정적 바이너리
CUBRID_API_TOKEN=secret123 ./cubrid_exporter --port 9890 --source statdump --dbs testdb,demodb

# 호출
curl -H "Authorization: Bearer secret123" http://cubrid-host:9890/metrics
운영에서는 TLS(리버스 프록시) 뒤에 두고, Prometheus 스크랩 계정에만 토큰을 부여하세요.

3. 엔드포인트

GET
/metrics — OpenMetrics(Prometheus exposition). 전체 DB·메트릭.
GET
/v1/stat/all?db=<name> — 전체 그룹 JSON(db 생략 시 전체 DB).
GET
/v1/stat/<group>?db= — 그룹별 JSON. group: database activity io lock bgwriter ha space availability.
GET
/v1/databases — 감시 DB 목록.
GET
/healthz — 헬스체크.

4. Prometheus 연동 (PostgreSQL 과 동일 방식)

PostgreSQL 이 postgres_exporter의 /metrics를 스크랩하는 것과 동일하게, 아래 스크랩 잡만 추가하면 됩니다. 변환 어댑터 개발이 필요 없습니다.

scrape_configs:
  - job_name: cubrid
    metrics_path: /metrics
    static_configs:
      - targets: ['cubrid-host:9890']
    # 토큰 사용 시
    authorization:
      type: Bearer
      credentials: secret123

실제 /metrics 출력 예시 mock 샘플(라이브 익스포터 미접속)

# HELP cubrid_up Whether the CUBRID database is reachable (1=up, 0=down).
# TYPE cubrid_up gauge
cubrid_up{db="testdb"} 1
cubrid_up{db="demodb"} 1
# HELP cubrid_uptime_seconds Seconds since the database server started.
# TYPE cubrid_uptime_seconds gauge
cubrid_uptime_seconds{db="testdb"} 3601
cubrid_uptime_seconds{db="demodb"} 3601
# HELP cubrid_snapshot_age_seconds Age of the cached snapshot this scrape served (freshness).
# TYPE cubrid_snapshot_age_seconds gauge
cubrid_snapshot_age_seconds{db="testdb"} 0
cubrid_snapshot_age_seconds{db="demodb"} 0
# HELP cubrid_xact_commits_total Number of committed transactions.
# TYPE cubrid_xact_commits_total counter
cubrid_xact_commits_total{db="testdb"} 1042
cubrid_xact_commits_total{db="demodb"} 2042
# HELP cubrid_xact_rollbacks_total Number of rolled-back transactions.
# TYPE cubrid_xact_rollbacks_total counter
cubrid_xact_rollbacks_total{db="testdb"} 1002
cubrid_xact_rollbacks_total{db="demodb"} 2002
# HELP cubrid_sql_selects_total SQL SELECT statements executed (statement count, not rows).
# TYPE cubrid_sql_selects_total counter
# HELP cubrid_sql_inserts_total SQL INSERT statements executed.
# TYPE cubrid_sql_inserts_total counter
# HELP cubrid_sql_updates_total SQL UPDATE statements executed.
# TYPE cubrid_sql_updates_total counter
# HELP cubrid_sql_deletes_total SQL DELETE statements executed.
# TYPE cubrid_sql_deletes_total counter
# HELP cubrid_seq_scans_total Sequential scans performed.
# TYPE cubrid_seq_scans_total counter
# HELP cubrid_idx_scans_total Index scans performed.
# TYPE cubrid_idx_scans_total counter
# HELP cubrid_blks_fetched_total Data pages fetched from the buffer (hit + read).
# TYPE cubrid_blks_fetched_total counter

PromQL 예시 (PG 대시보드와 동형)

# 캐시 히트율
rate(cubrid_blks_hit_total[5m])
  / (rate(cubrid_blks_hit_total[5m]) + rate(cubrid_blks_read_total[5m]))

# 초당 트랜잭션(TPS)
rate(cubrid_xact_commits_total[1m]) + rate(cubrid_xact_rollbacks_total[1m])

# 활성 세션
cubrid_sessions{state="active"}

# 복제 지연(초)
cubrid_ha_replication_delay_seconds

5. Grafana

Grafana 는 Prometheus 를 데이터소스로 추가해 위 PromQL 로 패널을 구성합니다. 메트릭이 counter/gauge·라벨 구조에서 PostgreSQL 과 동형이므로, 기존 PostgreSQL 대시보드를 복제해 메트릭 접두사만 pg_→cubrid_ 로 바꾸면 대부분 재사용됩니다.

CUBRID 전용 Grafana 플러그인은 없으므로 Prometheus 경유가 표준 경로입니다(PostgreSQL 의 Prometheus 경로와 동일 수준).

6. 메트릭 레퍼런스 (40개)

가용성 · 스크랩 메타 db_stat_up ≈ pg_up / scrape meta

메트릭타입단위라벨소스 (CUBRID / PG)설명
cubrid_up gauge bool db server ping DB 접속 가능 여부(1=정상, 0=다운).
cubrid_uptime_seconds gauge seconds db server start 서버 기동 이후 경과 시간(초).
cubrid_snapshot_age_seconds gauge seconds db cache 이번 스크랩이 서빙한 캐시 스냅샷의 신선도(초).

핵심 통계(트랜잭션·쿼리·버퍼) db_stat_database ≈ pg_stat_database

메트릭타입단위라벨소스 (CUBRID / PG)설명
cubrid_xact_commits_total counter — db Num_tran_commits
PG: xact_commit		 커밋된 트랜잭션 수.
cubrid_xact_rollbacks_total counter — db Num_tran_rollbacks
PG: xact_rollback		 롤백된 트랜잭션 수.
cubrid_sql_selects_total counter — db Num_query_selects
PG: ~tup_returned		 실행된 SELECT 문 수(행 수가 아님).
cubrid_sql_inserts_total counter — db Num_query_inserts
PG: ~tup_inserted		 실행된 INSERT 문 수.
cubrid_sql_updates_total counter — db Num_query_updates
PG: ~tup_updated		 실행된 UPDATE 문 수.
cubrid_sql_deletes_total counter — db Num_query_deletes
PG: ~tup_deleted		 실행된 DELETE 문 수.
cubrid_seq_scans_total counter — db Num_query_sscans
PG: ~seq_scan		 순차 스캔 횟수.
cubrid_idx_scans_total counter — db Num_query_iscans
PG: ~idx_scan		 인덱스 스캔 횟수.
cubrid_blks_fetched_total counter pages db Num_data_page_fetches
PG: blks_hit+blks_read		 버퍼에서 fetch 한 데이터 페이지 수(히트+읽기).
cubrid_blks_read_total counter pages db Num_data_page_ioreads
PG: blks_read		 디스크에서 읽은 데이터 페이지 수(버퍼 미스).
cubrid_blks_hit_total counter pages db fetches - ioreads (derived)
PG: blks_hit		 버퍼에서 바로 제공된 데이터 페이지 수(fetch-읽기).
cubrid_temp_pages_total counter pages db Num_sort_io_pages
PG: ~temp_files		 디스크로 넘친 임시/정렬 페이지 수.

연결 · 세션 db_stat_activity ≈ pg_stat_activity

메트릭타입단위라벨소스 (CUBRID / PG)설명
cubrid_sessions gauge — db state session table
PG: pg_stat_activity_count{state}		 상태별 현재 세션 수(active/idle/waiting/total).
cubrid_max_clients gauge — db config max_clients
PG: max_connections		 설정된 최대 클라이언트 수.
cubrid_oldest_xact_seconds gauge seconds db tranlist
PG: max(now-xact_start)		 가장 오래 실행 중인 트랜잭션의 수명(초).

입출력(I/O) db_stat_io ≈ pg_statio_*

메트릭타입단위라벨소스 (CUBRID / PG)설명
cubrid_data_pages_read_total counter pages db Num_data_page_ioreads 디스크에서 읽은 데이터 페이지.
cubrid_data_pages_written_total counter pages db Num_data_page_iowrites 디스크로 기록한 데이터 페이지.
cubrid_log_pages_read_total counter pages db Num_log_page_ioreads 디스크에서 읽은 로그 페이지.
cubrid_log_pages_written_total counter pages db Num_log_page_iowrites 디스크로 기록한 로그 페이지.
cubrid_file_reads_total counter — db Num_file_ioreads 파일 단위 읽기 연산 수.
cubrid_file_writes_total counter — db Num_file_iowrites 파일 단위 쓰기 연산 수.
cubrid_page_size_bytes gauge bytes db db page size DB 페이지 크기(바이트). 페이지→바이트 환산용.

잠금 · 대기 db_stat_lock ≈ pg_locks

메트릭타입단위라벨소스 (CUBRID / PG)설명
cubrid_locks_acquired_total counter — db Num_object_locks_acquired 획득한 객체 잠금 수.
cubrid_locks_waits_total counter — db Num_object_locks_waits 객체 잠금 대기 발생 수.
cubrid_lock_wait_seconds_total counter seconds db Num_object_locks_time_waited_usec / 1e6 객체 잠금 대기에 소요된 누적 시간(초).
cubrid_lock_current_waiters gauge — db lock table
PG: count(pg_locks.granted=false)		 현재 잠금을 대기 중인 세션 수.

체크포인트 · 플러시 db_stat_bgwriter ≈ pg_stat_bgwriter

메트릭타입단위라벨소스 (CUBRID / PG)설명
cubrid_pages_flushed_total counter pages db Num_data_page_flushed
PG: buffers_clean		 백그라운드 라이터가 플러시한 데이터 페이지.
cubrid_adaptive_flush_pages_total counter pages db Num_adaptive_flush_pages 적응형 플러시로 기록한 페이지.
cubrid_checkpoints_total counter — db checkpoint count
PG: checkpoints_timed		 수행된 체크포인트 수.

복제 · HA db_stat_ha ≈ pg_stat_replication

메트릭타입단위라벨소스 (CUBRID / PG)설명
cubrid_ha_node_info gauge info db node role state heartbeat HA 노드 역할/상태(info 패턴, 값은 항상 1).
cubrid_ha_replication_delay_seconds gauge seconds db node DELAY_IN_SECS (log_applier)
PG: replay_lag		 슬레이브 노드의 복제 지연(초).
cubrid_ha_copy_log_lag_pages gauge pages db node copylogdb copylogdb 지연(로그 페이지).
cubrid_ha_apply_log_lag_pages gauge pages db node applylogdb applylogdb 지연(로그 페이지).

저장 공간 db_stat_space ≈ pg_database_size

메트릭타입단위라벨소스 (CUBRID / PG)설명
cubrid_space_total_bytes gauge bytes db spacedb total
PG: pg_database_size		 DB 전체 크기(바이트).
cubrid_space_data_bytes gauge bytes db data volumes 데이터 볼륨 크기(바이트).
cubrid_space_free_bytes gauge bytes db free space 여유 공간(바이트).
cubrid_space_used_ratio gauge ratio db used/total 공간 사용률(0~1).
